# Eksploracyjna Analiza Danych (EDA) – Loty w Indiach

## O projekcie
Niniejsze repozytorium zawiera projekt zaliczeniowy z zakresu analizy danych, którego celem jest dogłębna eksploracyjna analiza (EDA) indyjskiego rynku lotniczego. Projekt skupia się na identyfikacji kluczowych czynników wpływających na ceny biletów lotniczych w zależności od wybranych parametrów podróży.

Dokumentacja oraz pełen raport z analizy zostały wygenerowane z użyciem R Markdown do formatu HTML.

## Cel biznesowy analizy
Zrozumienie strategii cenowych głównych przewoźników lotniczych w Indiach oraz odpowiedź na pytania:
* Jak zmienia się cena biletu w zależności od czasu pozostałego do wylotu?
* Jaka jest dysproporcja cenowa między klasą ekonomiczną a biznesową?
* Które linie lotnicze oferują najbardziej budżetowe, a które najbardziej luksusowe opcje?
* Jak liczba przesiadek oraz miasto docelowe wpływają na ostateczny koszt podróży?

## Technologie i narzędzia
* **Język:** R
* **Środowisko:** RStudio
* **Główne pakiety:** `tidyverse`, `dplyr` (manipulacja danymi), `ggplot2` (wizualizacja danych)
* **Raportowanie:** R Markdown
